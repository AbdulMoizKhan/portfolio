# Areeba Ashraf Ali Finance & SAP Business One Portfolio

A polished React portfolio website for **Areeba Ashraf Ali**, a Certified SAP Business One Consultant with an ACCA and Oxford Brookes University accounting and finance background. The site presents Areeba's SAP Business One consulting capabilities, finance experience, credentials, volunteering, languages, and LinkedIn contact information in a clean corporate dashboard style.

## Project Overview

This portfolio is designed for a professional finance, consulting, ERP, and SAP Business One audience. It uses card-based sections, KPI-style hero stats, a consulting focus panel, and a career timeline to communicate implementation support, data migration, financial process configuration, stakeholder collaboration, and user training experience.

## Tech Stack

- Vite
- React
- Modern JavaScript modules
- Custom responsive CSS
- Dynamic content stored in `src/data/profile.js`

## Setup Instructions

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

## Deployment

### Vercel

1. Push this repository to GitHub, GitLab, or Bitbucket.
2. Import the project in Vercel.
3. Keep the default Vite settings:
   - Build command: `npm run build`
   - Output directory: `dist`
4. Deploy the project.

### Netlify

1. Push this repository to a Git provider.
2. Create a new Netlify site from the repository.
3. Use these build settings:
   - Build command: `npm run build`
   - Publish directory: `dist`
4. Deploy the site.

## Content Updates

Most portfolio content is centralized in `src/data/profile.js`. Update that file to adjust hero stats, expertise cards, experience timeline entries, education, certifications, volunteering, languages, or LinkedIn details.
